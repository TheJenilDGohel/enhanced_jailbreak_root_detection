# Security Policy 🛡️

## Supported Versions
We only support the latest version of the plugin. Please update to the latest release before reporting a vulnerability.

| Version | Supported          |
| ------- | ------------------ |
| v0.0.x  | ✅ Supported       |
| < v0.0.1| ❌ Not Supported    |

## Reporting a Vulnerability
Security is at the heart of this project. If you find a way to bypass our detection or discover a security flaw in the implementation:

1. **Do not open a public issue.**
2. Email the maintainer at [j.d.gohel4200@gmail.com](mailto:j.d.gohel4200@gmail.com) with the subject "Security Vulnerability".
3. Provide a detailed description of the vulnerability and steps to reproduce (or a proof-of-concept).

We will acknowledge your report within 48 hours and work on a fix as quickly as possible.

## Disclosure Policy
We follow a 90-day responsible disclosure policy. We ask that you do not share information about the vulnerability until a fix is released.

Thank you for helping keep the Flutter community secure!
